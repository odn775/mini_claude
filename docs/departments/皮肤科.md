# 皮肤科

## 科室名称

皮肤科（门诊）

## 适用症状

- 皮肤出现红斑、丘疹、风团，伴瘙痒
- 湿疹、皮炎反复发作，皮肤干燥脱屑
- 痤疮（青春痘）、毛囊炎、疖肿
- 脱发、头皮屑明显增多
- 手足癣、股癣、甲癣（灰指甲）
- 带状疱疹（沿神经分布的水疱伴疼痛）
- 色素痣近期增大、变色、边缘不规则
- 荨麻疹反复发作，或接触某物后出现皮疹

## 不适用与鉴别

- **全身皮疹伴呼吸困难、喉头发紧、血压下降**：警惕过敏性休克，立即急诊或拨打 120。
- 皮疹伴高热、口腔或眼部黏膜糜烂：可能为重症药疹，建议急诊。
- 儿童（14 岁以下）皮疹伴发热：优先儿科，必要时儿科转诊皮肤科。
- 外阴、肛周瘙痒或皮损：可先挂皮肤科，部分医院分设妇科或肛肠科。
- 皮肤溃烂长期不愈、伴明显疼痛或渗液：需排除其他病变，建议皮肤科面诊。
- 单纯美容需求（祛斑、嫩肤）：属医疗美容科，不在普通皮肤科门诊范围。

## 就诊提示

- 建议挂皮肤科普通号；皮疹范围大、反复不愈或需病理检查时可挂专家号。
- 就诊前 24 小时避免在患处涂抹药膏、粉底或护肤品，以免影响观察。
- 拍照记录皮疹出现时间和变化过程，便于医生判断。
- 如怀疑接触过敏，带上可疑物品（化妆品、首饰、外用药）或拍照。
- 就诊时告知既往过敏史、近期用药史（尤其新使用的药物）。
