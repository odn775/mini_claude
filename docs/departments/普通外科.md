# 普通外科

## 科室名称

普通外科（门诊）

## 适用症状

- 体表或皮下出现肿块、结节，需要判断是否需要处理
- 乳腺肿块、乳头溢液、乳房疼痛
- 疝气（腹股沟或腹部用力时鼓包）
- 反复右下腹或右上腹疼痛，怀疑阑尾、胆囊问题但目前已不剧烈
- 胆囊结石、胆息肉等体检发现，需要评估是否手术
- 痔疮、肛裂、肛周疼痛或便血（鲜红色）
- 伤口感染、换药、拆线，小面积烧烫伤换药
- 甲状腺结节、淋巴结肿大需要穿刺或手术评估
- 静脉曲张、下肢溃疡

## 不适用与鉴别

- **突发剧烈腹痛、腹肌紧张、呕吐不止、停止排气排便**：可能是急腹症，立即急诊，
  不要等到门诊。
- 便血伴消瘦、排便习惯改变、家族肠癌史：优先消化内科做肠镜。
- 尿路结石、排尿困难、睾丸疼痛：优先泌尿外科。
- 女性下腹痛、阴道出血、盆腔包块：优先妇产科。
- 乳腺问题伴发热红肿（急性乳腺炎）：哺乳期可先到妇产科或乳腺专科。
- 甲状腺功能异常（甲亢、甲减）先到内分泌科，结节需要手术时才转普通外科。

## 就诊提示

- 挂「普通外科」普通号即可，肿块类问题建议上午就诊，便于当天完成超声检查。
- 记录肿块发现时间、大小变化、是否疼痛、是否随月经周期变化（乳腺）。
- 携带既往超声、CT、胃肠镜报告；准备手术评估者请带上近期血常规与凝血功能。
- 就诊前不要自行挤压、热敷或用偏方处理肿块与伤口，避免加重感染。
