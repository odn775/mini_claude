# 内科（普通内科）

## 科室名称

内科（普通内科，系统中对应科室名：全科医学科）

## 适用症状

- 说不清具体是哪个部位或哪个系统的不适，需要先做初步判断
- 同时有两三个系统的症状（如乏力加轻微头晕、食欲差）
- 低热、乏力、体重轻度下降等全身性症状，持续一周以上未缓解
- 体检报告出现异常指标（血常规、肝肾功能、血脂、血糖），需要解读方向与复查建议
- 高血压、糖尿病、高血脂等慢性病的常规随访与开药
- 已在专科确诊、需要长期复诊配药或开检查单
- 外院或外省就诊后，需要有人帮忙整理下一步该挂哪个科
- 感冒、咽痛、轻度胃肠不适等常见轻症的首诊

## 不适用与鉴别

- **胸痛、呼吸困难、意识不清、大出血、抽搐**：立即急诊或拨打 120，不走门诊流程。
- 症状明确指向单一系统时优先对应专科：咳嗽咳痰→呼吸内科，心悸胸闷→心血管内科，
  反酸腹痛→消化内科，关节肿痛→风湿免疫科。
- 14 岁以下儿童：优先儿科。
- 孕期、月经相关问题：优先妇产科。
- 需要手术评估的问题（肿块、疝、结石、白内障）：先到对应外科或眼科，普通内科只能初筛。
- 持续发热超过 3 周且原因不明：感染科或发热门诊。

## 就诊提示

- 普通内科适合作为「第一站」，不确定挂什么科时先挂它，医生会给出转诊方向。
- 携带近三个月的体检报告、既往病历、正在服用的药物清单（含保健品）。
- 慢性病复诊建议带上上次的处方和最近的化验单，空腹前往以便当场抽血。
- 初诊一般先做基础检查（血常规、尿常规、肝肾功能、血糖），不必提前自行加做昂贵项目。
