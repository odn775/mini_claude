# 消化内科

## 科室名称

消化内科（门诊）

## 适用症状

- 上腹疼痛、腹胀、反酸、烧心、嗳气
- 恶心、呕吐，尤其反复发作或与进食相关
- 腹泻超过 3 天，或反复腹泻便秘交替
- 便秘持续 2 周以上，调整饮食后无改善
- 黑便、柏油样便（提示消化道出血）
- 皮肤或眼白发黄（黄疸）
- 吞咽困难、进食后梗噎感
- 体检发现肝功能异常、幽门螺杆菌阳性

## 不适用与鉴别

- **呕血、大量黑便、剧烈腹痛伴冷汗**：属急危重症，立即急诊或拨打 120。
- 右下腹持续疼痛、按压后更痛、伴发热：警惕阑尾炎，建议急诊或普通外科。
- 腹痛伴尿频尿急、腰痛：优先泌尿外科或肾内科。
- 女性下腹痛伴异常阴道出血：优先妇产科。
- 儿童（14 岁以下）腹泻呕吐：优先儿科。
- 以胸骨后烧灼感为主且与活动相关：需先排除心血管问题，可挂心血管内科。

## 就诊提示

- 建议挂消化内科普通号；反复发作或需胃镜/肠镜检查时按医院流程预约。
- 就诊前记录疼痛部位、与进食的关系、大便次数与性状（是否带血或发黑）。
- 做胃镜、肠镜通常需空腹，具体禁食时间以医院预约单为准；如长期服用抗凝药请提前告知医生。
- 携带既往胃肠镜报告、肝功能与幽门螺杆菌检测结果。
