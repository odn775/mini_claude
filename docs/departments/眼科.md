# 眼科

## 科室名称

眼科（门诊）

## 适用症状

- 眼睛发红、疼痛、异物感、分泌物增多
- 视力下降或看东西模糊，逐渐加重或突然出现
- 流泪、畏光、频繁眨眼、眼干涩
- 看东西有黑影飘动（飞蚊症）、闪光感
- 眼外伤、异物入眼、化学品溅入
- 眼睑红肿、长包（麦粒肿、霰粒肿）
- 体检发现眼压高、眼底异常、白内障、糖尿病视网膜病变
- 儿童视力筛查、斜视弱视、需要验光配镜
- 青光眼家族史需要定期随访

## 不适用与鉴别

- **化学物溅入眼、眼球穿通伤、突然无痛性视力丧失**：属于眼科急症，立即就诊或拨打 120，
  不要自行冲洗（化学品除外按现场急救要求冲洗后立即就医）。
- 眼红伴明显头痛、恶心呕吐、看灯有彩色光圈：可能是急性闭角型青光眼，需急诊处理。
- 偏头痛相关的闪光、视觉先兆伴头痛：神经内科。
- 眼睑肿物、眼周皮肤红肿瘙痒：眼科与皮肤科联合就诊。
- 儿童发热出疹伴眼红（如麻疹、川崎病）：先儿科。

## 就诊提示

- 视力下降、眼痛、眼外伤建议当天就诊，夜间到急诊眼科（部分医院需转诊）。
- 就诊前不要自行戴隐形眼镜，检查当天素颜前往，避免影响眼部检查。
- 需要散瞳检查时会短时间视物模糊，当天不要开车，最好有人陪同。
- 带上正在使用的眼药水、眼镜或隐形眼镜处方，以及既往眼底照片与 OCT 报告。
