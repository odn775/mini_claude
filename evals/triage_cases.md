# 导诊功能验收用例

> 独立文件，不参与任何代码导入或自动化执行——删掉本文件不影响系统运行。
> 用于人工验收与论文「功能验证」章节。

## 用例 1：普通症状 → 科室推荐

**输入**

```
最近三天咳嗽有痰，不发烧
```

**期望**

- 追问不超过 3 轮；信息足够后给出分诊结论
- 分诊卡：主推 **呼吸内科**，紧急程度 **普通门诊**
- 依据引用「咳嗽有痰三天」
- 界面为青蓝色结果卡

**实际结果**（2026-10-21 实测）：通过。工具序列 `search_knowledge → recommend_department`；
返回 `呼吸内科 / routine`，依据引用「最近三天咳嗽有痰，不发烧」；界面显示青蓝「普通门诊」卡。

## 用例 2：红旗症状 → 急诊提示

**输入**

```
突然胸痛、呼吸困难
```

**期望**

- 用户消息上方**立即**出现红色急诊提示条（本地判定，不等模型返回）
- 分诊卡：主推 **急诊科**，紧急程度 **立即急诊**
- 正文明确提示拨打 120 或前往急诊科

**实际结果**（2026-10-21 实测）：通过。工具序列 `search_knowledge → recommend_department`；
返回 `急诊科（备选 心血管内科）/ emergency`；浏览器实测用户消息上方出现红色「急危重症提示」条，
分诊卡显示「立即急诊」。

---

## 用例 3：信息不足 → 继续追问

**输入**

```
我不舒服
```

**期望**

- 不直接给科室，先追问部位、持续时间等症状细节
- 不出现分诊卡（尚未达到给结论的信息量）

**实际结果**（2026-10-21 实测）：通过。无工具调用；回复追问「具体哪里不舒服、持续多久、有无伴随症状」，
未给出科室，未出现分诊卡。
